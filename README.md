# Meeting-Parser

- 项目是什么：个人使用的浏览器媒体资源嗅探与下载工具。
- 解决的需求：在用户已正常登录并播放视频时，找出浏览器实际请求的媒体资源。
- 核心功能：识别、去重并展示 MP4、HLS（m3u8）、DASH（mpd）候选资源；直接下载 MP4。
- 第一阶段：重点验证腾讯会议录制页面暴露的真实媒体格式与直接 MP4 下载。

## 使用

1. 在 Chrome 或 Edge 的扩展管理页开启“开发者模式”，选择“加载已解压的扩展程序”，并选择仓库中的 `extension/` 目录，不要选择仓库根目录。
2. 在项目目录运行本地下载器：`python local_downloader.py`。
3. 正常登录并打开录制页面，播放视频。
4. 打开插件面板查看媒体候选资源；MP4 点击“下载 MP4”后由本地下载器流式保存到 Downloads 目录。

本地下载器只监听 `127.0.0.1:8765`，插件会先检查 `/health`；未启动时请先运行上面的命令。

## 范围

- 复用用户正常登录、正常播放时的浏览器请求；不处理登录、签名、Token 或 DRM。
- HLS/DASH 仅识别和展示，不下载分片、不合并媒体。
